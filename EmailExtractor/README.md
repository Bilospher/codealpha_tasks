# CodeAlpha Email Extractor

A simple Python-based Email Extractor developed as part of the **CodeAlpha Python Programming Internship**.

## 📌 Project Overview

This program reads a text file containing email addresses and other text, extracts the email addresses using a regular expression, removes duplicate addresses, sorts the results, and saves the extracted addresses into a separate text file.

## ✨ Features

* Reads email data from a text file
* Extracts email addresses using regular expressions
* Removes duplicate email addresses
* Sorts the extracted addresses
* Saves the results to a separate text file
* Works with different email domains

## 🛠️ Concepts Used

* Python
* Regular Expressions (`re`)
* File Handling
* Reading and writing text files
* Lists
* `set()`
* `sorted()`
* String processing

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/Bilospher/CodeAlpha_EmailExtractor.git
```

Open the project folder:

```bash
cd CodeAlpha_EmailExtractor
```

Run the program:

```bash
python Email_Extractor.py
```

## 📄 Project Files

* `Email_Extractor.py` — Main Python program
* `Dummy_Email_Contacts.txt` — Input text file containing sample email data
* `Email Addresses.txt` — Output file containing the extracted email addresses
