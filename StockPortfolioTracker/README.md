# CodeAlpha Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker developed as part of the **CodeAlpha Python Programming Internship**.

## 📌 Project Overview

This program allows the user to select stocks, enter the quantity they want to buy, and calculate the total investment based on predefined stock prices.

The stock prices are stored in a Python dictionary, and the program calculates the investment using basic arithmetic.

## ✨ Features

* Predefined stock prices for:

  * AAPL
  * TSLA
  * MSFT
  * GOOGL
* User input for stock selection
* User input for stock quantity
* Investment calculation for each stock
* Calculates the total investment
* Generates a text report of the portfolio

## 🛠️ Concepts Used

* Python
* Dictionaries
* Variables
* User input
* `while` loops
* Conditional statements
* Arithmetic operations
* File handling

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/Bilospher/CodeAlpha_StockPortfolioTracker.git
```

Open the project folder:

```bash
cd CodeAlpha_StockPortfolioTracker
```

Run the program:

```bash
python Stock_Portfolio_Tracker.py
```

## 📄 Project Files

* `Stock_Portfolio_Tracker.py` — Main Python program
* `Stock Portfolio Report.txt` — Generated portfolio report
